4. 結論

不能說「差非常多」,要分層看:

  • 程式碼與整合架構:差很多。我們的套件結構、模組分工、情緒鏈路、framed 連線、模式切換、前端串流,都是自己的設計與實作,教學裡沒有對應內容。
  • 元件與高層流程:相同,而且改不掉。我們和零度用的是同一組開源元件,流程也是語音對話數字人的通用流程;連接埠與啟動參數也依教學。這一層不是「做得不一樣」,而是「用了同樣的東西」。

所以如實的說法是:元件與流程層面與零度相同(同一組開源專案),架構與程式碼層面是我們自己的。建議在報告裡直接寫明參考了這篇教學(元件選型與安裝步驟),並說明我們早期系統在參考之前就已有相同的流程;這樣最站得住腳,也不需要靠「差多遠」來說服任何人。

注意:課程對 AI 輔助開發的規範我不了解,請對照規定決定要不要在報告中註明開發過程使用了 Claude Code。
